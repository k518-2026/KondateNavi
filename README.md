# こんだてナビ（Kondate Navi）

公開ページ.
https://k518-2026.github.io/KondateNavi/

「食材」「調理手段」「完成形」をチェックボックスで選ぶだけで、今の状況に合うレシピを2〜3件提案するサイトです。

- 食材: 冷蔵庫の残り物・缶詰・乾物・防災用保存食
- 調理手段: 電子レンジ・鍋・フライパン
- 完成形: 和風・洋風・中華・エスニック

提案されるのは具体的な作り方ではなく献立のヒントです。「Cookpadで探す」「クラシルで探す」のリンクから、条件に合う実際のレシピを検索できます。チェックを付けなかった項目は「どれでも可」として扱われます。

インストール不要・アカウント登録不要で、ブラウザーだけで動きます。入力したチェック内容がサーバーに送られることはありません。

ページ上部には「これまで◯回、レシピを提案しました」という通算カウンターがあります。これは全員分を合算した数値で、外部の無料カウンターAPI（[abacus](https://abacus.jasoncameron.dev/)）に記録しています。このAPIに接続できないときは、そのブラウザだけの回数にフォールバックして表示します。

## 仕組み

- `index.html` / `style.css` / `script.js`: 画面と提案ロジック
- `data.js`: 食材×調理手段×完成形の全組み合わせ（48パターン）の献立アイデア
- ビルド不要の静的サイト。GitHub Pages でそのまま公開できます
- 通算カウンターのみ外部API（abacus.jasoncameron.dev）を利用します。個人情報は送信しません
